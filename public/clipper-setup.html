选择你的浏览器

Chrome、Edge 和 Arc 使用同一个 ZIP 插件包。Safari 会复用同一套采集核心，但正式分发需要 Apple 签名。

Chrome

下载 ZIP 并解压，打开扩展程序页面，加载解压后的 `extensions/web-extension` 文件夹。

Edge

进入扩展页面，开启开发者模式，加载解压后的同一个插件目录。

Arc

兼容 Chrome 扩展，安装方式与 Chrome 基本一致。

Safari

需要 Safari Web Extension Host App。当前页面先作为配置和说明入口。

三步完成配置

开发预览版需要手动加载插件；正式发布后这里会替换为商店安装按钮。

1

加载插件目录

先下载本页的插件 ZIP 并解压。Chrome / Edge / Arc 打开扩展程序页面，开启开发者模式，选择解压后的 `extensions/web-extension`。

2

填入连接信息

点击浏览器工具栏里的 InfoMind Clipper，把本页的连接地址和配对码填进去。

3

保存当前页面

打开抖音、小红书、知乎或任意文章页，点击 Save to InfoMind，内容会进入书架和时间线。

它会收集什么

插件只在你点击保存时读取当前页面。InfoMind 不读取、不保存平台 Cookie。

标题与作者用于生成书架卡片、时间线和作者聚合。
正文与描述用于更准确分类，并生成 Article Mind Map。
图片与封面用于书籍封面和详情页视觉呈现。
字幕与视频信息有字幕时直接用于解读；无字幕时再进入转写流程。
Safari 用户：当前普通用户最顺畅的路径仍是 Chrome / Edge / Arc。Safari 版需要后续签名包装后才能像普通 App 一样安装。

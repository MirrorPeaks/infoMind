# InfoMind Clipper for Chrome / Edge / Arc

开发期安装方式：

1. 打开 `chrome://extensions`。
2. 开启右上角 Developer mode。
3. 点击 Load unpacked。
4. 选择本仓库的 `extensions/web-extension` 目录。
5. 打开 InfoMind 设置页，复制“浏览器收录插件”的连接地址和配对码。
6. 点击浏览器工具栏里的 InfoMind Clipper，填入地址和配对码。

正式面向普通用户分发时，应把 `extensions/web-extension` 打包并提交到 Chrome Web Store。设置页里的入口可以替换成商店安装链接。

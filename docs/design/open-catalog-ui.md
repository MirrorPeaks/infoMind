# InfoMind Open Catalog UI

## Direction

InfoMind is treated as a living private archive rather than a generic dashboard. The interface combines editorial typography, archival indexing, and restrained technical notation. It takes method-level cues from print magazines and catalog systems without copying another product's visual identity.

## Signature

- Warm neutral paper, white reading surfaces, near-black ink.
- Dusty rose is the only primary product accent: a thought point, active marker, or status signal.
- Newsreader is used for ideas and titles; Manrope for readable UI; monospace for structural metadata.
- Hairlines and whitespace create hierarchy. Shadows are reserved for overlays only.
- Corners remain between 0 and 6px. Pills are used only for compact status metadata.
- The Open Catalog symbol anchors every first-party surface in positive and reversed forms.

## Layout

- Desktop uses a 232px archival index rail and a wide editorial canvas.
- Bookshelf categories are horizontal archive bands: indexed category information on the left, aligned books on the right.
- Timeline entries follow one legible vertical axis instead of alternating cards.
- Insights retain trend-left and treemap-right ordering with equal visual height.
- Mobile uses a bottom command rail, two-column book grid, stacked charts, and full-screen detail surfaces.

## Interaction

- Motion is short and quiet: opacity and 4px translation, never decorative bounce.
- Hover reveals intent with ink, line, and small positional changes.
- Focus states use a visible rose outline and remain keyboard accessible.
- Existing letter-fold and mailbox capture choreography is preserved, with its surrounding chrome normalized to this system.
